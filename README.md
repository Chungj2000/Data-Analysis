# Data Analysis

A portfolio repository, which contains a collection of data analytics, data science, dashboard development, and data engineering projects completed through independent study, professional development programmes, and academic research.

## Featured Projects

### Chicago Crimes

**Tools:** Power BI, Power Query, MySQL, DAX Studio

An analytics project processing 8.5M+ records with the goal of effective resource allocation by identifying patterns within crime frequency across time, location, and type. It showcases extensive data cleaning and profiling, modeling into star schema using DAX Studio & MySQL to resolve query efficiency bottlenecks, as well as a dashboard created only with Power BI native visuals for compatability across systems.

### Email Classification Study

**Tools:** Python, Pandas, Scikit-learn, Jupyter Notebook

An machine learning project exploring how email characteristics can be used to distinguish legitimate messages from spam, with the aim of training a machine learning model with a 90% accuracy at correctly classifying emails into Spam and Ham. The project investigates feature importance, model evaluation, and classification performance using Logistic Regression, Naive Bayes, and Random Forest models.

### Customer Risk Assessment against Value

**Tools:** Python, Excel

A customer analytics project that builds upon my experiences of the 'Customer Churn & Value Analysis'. Using a larger dataset, this project aims to segment customers based on their customer lifetime value, and a feature engineered risk score associated with various risk components. This study focused more on feature selection and feature engineering of a risk score, then training a KMeans clustering model to group customers based oon their behaviour across value and risk. Each derived cluster would then be interpreted as action groups with corresponding tailored strategy recommendations to maximimise value.

📝 Status: `Complete` <br />
📁 Location: `Data Science/Customer Segmentation by Value & Risk`
